Step 1 · Learn

Organise, display, describe

Every set of numerical data goes through the same three moves. This page takes you through them in order.

  1. Organise it in a frequency table
  2. Display it in a histogram
  3. Describe it with SOCS

1. Organise: the frequency table

A frequency table counts how many values fall at each value or in each interval, and turns each count into a percentage:

Percentage = count ÷ total × 100

If the data takes only a few different values, give each value its own column. Here are the shoe sizes of 46 adults:

Size 8 is 12 ÷ 46 × 100 = 26.1%. The rounded percentages add to 99.9, which is fine (allow for rounding).

2. Display: the histogram

Here is the GDP table drawn as a histogram. Each interval becomes a bar:

  • The horizontal axis is a number scale, so the bars touch. A bar chart has gaps because its categories are separate.
  • Bar height is the frequency (or the percentage).

Reading it back. To answer a question from a histogram, add the bars you need, then divide by the total. Below $2000: 2 + 11 = 13 countries, and 13 ÷ 41 × 100 = 31.7%.

📘 In your textbook: Cambridge 1C, Example 8 “Constructing a histogram from a frequency table” (p. 16). Calculator steps: CAS 1 “How to construct a histogram” (TI-Nspire p. 16, ClassPad p. 18).

3. Describe: SOCS

Describe a histogram with SOCS, always in this order: Shape, Outliers, Centre, Spread. We will work through it on one histogram: the volume, in m³, of the trunks of 31 black cherry trees.

Data: VCAA 2023 NHT Exam 1, Questions 2–4 (‘Black Cherry Trees’, Wolfram Data Repository)
S
Shape. Find the long tail. The shape is named after the tail, not the peak.

The cherry trees peak on the left and tail off to the right: positively skewed.

O
Outliers. Look for a value cut off from the rest by a gap.

The tree in 2.0–2.2 m³ sits after an empty interval: a possible outlier at 2.0–2.2 m³. If nothing is cut off, say “no outliers”.

The shape earns the mark; adding a note on outliers is fine.
“Most students recognised the distribution was positively skewed. It was acceptable to add that there were no outliers.”
VCAA 2020 Exam 2 report, Question 1a (Further Mathematics; the display was a stem plot)
C
Centre. Find the interval holding the middle value.

31 trees, so the middle tree is the 16th. Count up the bars: 3, then 3 + 8 = 11, then 11 + 8 = 19. The 16th tree is in 0.6–0.8 m³.

S
Spread. Say where the values start and finish.

The volumes run from about 0.2 to 2.2 m³.

Put it together (teacher frame)
“The distribution of [variable] is [shape], with [a possible outlier at … / no outliers]. The centre is in [interval], and values range from about [low] to [high].”

The distribution of volume is positively skewed, with a possible outlier at 2.0–2.2 m³. The centre is in 0.6–0.8 m³, and volumes range from about 0.2 to 2.2 m³.

SOCS grows from here: 1D reads exact values from dot and stem plots · 1F adds the mean, median, mode, range, IQR and standard deviation · 1G tests outliers with fences · 1H adds the normal shape.

Step 5 · Reference sheet

Summary

  • Few values → list each value. Many values → group into equal intervals (lower end included).
  • A histogram has a number scale and touching bars. Total = sum of the bar heights.
  • Percentage = (sum of the bars you need) ÷ total × 100.
  • Describe with SOCS: Shape, Outliers, Centre, Spread. Skew is named after the long tail.

Equal-width intervals. $1000–$1999 means $1000 up to (not including) $2000; exactly $2000 goes in $2000–$2999.

2 · Display: histogram

Numerical data · number scale · bars touch (bar chart = categorical, gaps)

Reading a histogram

  1. Total = add all the bar heights (2 + 11 + … = 41).
  2. Count = add the bars you need. Below $2000: 2 + 11 = 13.
  3. % = count ÷ total × 100 = 13 ÷ 41 × 100 = 31.7%.
  4. Middle value of n: count up the bars to the (n + 1) ÷ 2 th value. 41 → 21st → $2000–$2999.

3 · Describe: SOCS

  • Shape: name the long tail.
  • Outliers: a value cut off by a gap, or “no outliers”.
  • Centre: the interval holding the middle value.
  • Spread: where the values start and finish.

“Positively skewed, with a possible outlier at 2.0–2.2 m³. Centre in 0.6–0.8 m³; values range from about 0.2 to 2.2 m³.”

⚠ Exam traps

  • Set the outlier aside, then compare the tails. 54% called the possum skulls “approximately symmetric with a possible outlier”; the answer was negatively skewed with a possible outlier (VCAA 2022 Exam 1 Q1, 36% correct).
  • Count × value for a total: 20% gave 39 customers instead of 138 avocados (VCAA 2025 Exam 1 Q2).
  • The middle value is the middle data value, not the middle of the axis: 17% chose 3.5 (VCAA 2025 Exam 1 Q1).
  • Percent means ÷ total: 12 possums is 26%, not 12% (VCAA 2022 Exam 1 Q2).
  • “Skewed” is only for one variable, never a scatterplot (VCAA 2014 Exam 2 report).
