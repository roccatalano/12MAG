Today’s lesson

Today’s lesson

Learning intentions

  • To be able to determine by multiplication when two matrices are inverses.
  • To be able to determine the determinant of a 2 × 2 matrix.
  • To be able to determine the inverse of a 2 × 2 matrix.
  • To be able to use a CAS calculator to determine the inverse and determinant of an n × n matrix.
  • To be able to solve simple matrix equations.

Success criteria

  • I can recognise that two matrices are inverses if their product is the identity matrix.
  • I can evaluate the determinant of a 2 × 2 matrix by hand.
  • I can calculate the inverse of a 2 × 2 matrix by hand.
  • I can calculate the inverse and determinant of an n × n matrix using CAS.
  • I can solve simple matrix equations.

The inverse matrix

Matrices can’t be divided: we multiply by an inverse

  • the identity matrix I acts like the number 1: AI = IA = A
  • A and B are inverses if AB = I and BA = I; we write B = A−1
  • to show two matrices are inverses: multiply both ways and get I each time

The determinant of a 2 × 2 matrix

One number that tells you if an inverse exists

  • det(A) = ad − bc: leading diagonal product minus the other diagonal product
  • it can be positive, negative or zero
  • det = 0 → singular: no inverse

Solving matrix equations

Undo a matrix by multiplying by its inverse, on the SAME side

  • B + X = C → X = C − B
  • BX = C (B on the left) → pre-multiply: X = B−1C
  • XB = C (B on the right) → post-multiply: X = CB−1
  • order matters: B−1C ≠ CB−1 in general
AX = BX = A−1B
XA = BX = BA−1
BX = C
B−1BX = B−1C
IX = B−1C
X = B−1C
Write the order of X first: it tells you if the product is defined.
