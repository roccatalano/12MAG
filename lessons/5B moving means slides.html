Key ideas

Key definitions and formulas

Key definitions

Smoothingreplacing each value by the mean of it and its neighbours: irons out irregular fluctuations so the trend shows
Three-moving meanthe mean of a value and the one value on each side
Five-moving meanthe mean of a value and the two values on each side
Lost pointsan n-moving mean (n odd) has no value for the first and last (n − 1) ÷ 2 points

Key formulas

Three-meansmoothed y2 = y1 + y2 + y33
Five-meansmoothed y3 = y1 + y2 + y3 + y4 + y55
Number of smoothed pointsN − (n − 1)N data points, n-moving mean

Smoothing with a three-moving mean

Three-moving mean

  • irregular fluctuations can hide the trend: smoothing irons them out
  • replace each value by the mean of it and the one on each side
  • slide the window of three along one place at a time
  • the first and last values have no neighbour on one side: no smoothed value
Three-meansmoothed y2 = y1 + y2 + y33
Plot each smoothed value at the CENTRE of its window (the middle time).
Cambridge General Mathematics Units 3&4, 5B pp. 268–269 (data: Example 8)
Learn · 5B

Five-moving means and lost points

Five-moving mean

  • the mean of the value and the two on each side
  • the first two and last two values get no smoothed value
  • more points in the mean → smoother plot, but more points lost
  • N values, n-moving mean: N − (n − 1) smoothed values
Five-meansmoothed y3 = y1 + … + y55
Lost points(n − 1) ÷ 2 at each end
● raw data   ■ 3-moving mean   ■ 5-moving mean
Five-mean smoothing shows no clear trend, although the raw data suggest an increase.

Moving means in a spreadsheet

Use a spreadsheet to find the three-moving mean smoothed number of births for each month (Example 8 data).

month123456789101112
births1012652218137910815
Column A = month, column B = births, C2: =(b1+b2+b3)/3, copied down to C11.

TI-Nspire

  1. Lists & Spreadsheet: enter the time (1, 2, 3 …) in column A (name it e.g. day) and the values in column B (e.g. rainfall).
  2. Three-mean: in cell C2 type =(b1+b2+b3)/3 and press enter (C1 stays blank: no smoothed value for the first point).
  3. Select C2, drag its bottom-right corner down to the second-last row to copy the formula.
  4. Five-mean: start in C3 with =(b1+b2+b3+b4+b5)/5 and copy down to the third-last row.

ClassPad

  1. Spreadsheet app: enter the time (1, 2, 3 …) in column A and the values in column B.
  2. Three-mean: select C2, type =(B1+B2+B3)/3 and press EXE (C1 stays blank).
  3. Select C2 and drag down to the second-last row to copy the formula.
  4. Five-mean: start in C3 with =(B1+B2+B3+B4+B5)/5 and copy down to the third-last row.
