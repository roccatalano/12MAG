Calculating seasonal indices

Compare each season with the seasonal average

  • one year: seasonal average = mean of that year’s seasons; SI = season ÷ average
  • several years: do this for every year, then average each season’s SIs
  • check: the SIs add to the number of seasons
Seasonal indexvalue for seasonseasonal average
CheckSIs add to the number of seasons
1. Find the seasonal (yearly) average: add the seasons, divide by how many there are.
2. Divide each season’s value by that average → that year’s SIs.
3. Several years? Repeat for each year, then find the mean SI for each season.
4. Check: 4 quarters → SIs add to 4 · 12 months → 12 · 7 days → 7.
Keep 3 decimal places until the final average, then round as asked.

Learn · 5D

Why deseasonalise?

Take the seasons out to see the trend

  • deseasonalised value = actual ÷ SI
  • the seasonal ups and downs are removed
  • the underlying trend is clearer
  • deseasonalise before fitting a trend line (5E)
DeseasonaliseactualSI
Actual customers
Deseasonalised customers
Actual: hard to tell if Mikki’s shop is growing · Deseasonalised: a clear increasing trend.
Deseasonalised values are not the real numbers: reseasonalise (× SI) to get actual values back.
