Weight of a treethe sum of the weights of its edges
Minimum spanning treethe spanning tree with the smallest total weight
Prim’s algorithmgrow the tree one cheapest new edge at a time

Trees and spanning trees

As few edges as possible

  • a tree is connected and has no loops, multiple edges or cycles
  • n vertices → n − 1 edges
  • a spanning tree is a tree inside a graph that reaches every vertex
  • its weight is the sum of its edge weights
Treee = v − 1, no cycles
Spanning treereaches every vertex
7 vertices, 6 edges
Add any edge → a cycle appears: no longer a tree
Remove any edge → disconnected: no longer a tree
A graph usually has many spanning trees. Count first: you must keep exactly v − 1 edges.

Prim’s algorithm

Grow the cheapest tree

  1. start at any vertex
  2. take the cheapest edge from it
  3. look at every edge leaving the tree so far; take the cheapest one that reaches a new vertex
  4. skip edges that would make a cycle, loop or double edge
  5. repeat until every vertex is joined (v − 1 edges); add the weights
Minimum spanning treesmallest total weight
Primcheapest edge to a new vertex
Start at A: 2 to B
From A or B: 5 to D
Ties? Either edge is fine.
Write the edges in the order you choose them: it is your working.

Minimum connector problems

Connect everything, cheapest

  • pipes, cables, roads that must reach every location
  • the cheapest way = the minimum spanning tree
  • answer = the tree drawn + its total weight (with units)
Connector problemminimum spanning tree
Gas pipes to towns, cables to rides, water to outlets
Start Prim at the source (here the tank)
Key words: “connect all”, “minimum length of cable / pipe”, “least cost to join”.
