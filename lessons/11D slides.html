Key ideas

Key definitions and formulas

Key definitions

Matrix Bcolumn matrix (same order as Sn): the number added (+, restocking) or removed (−, culling) in each state every step
Cullingremoving animals from a population: negative elements in B
Restockingadding to a population: positive elements in B

Key formulas

Next stateSn+1 = T Sn + Bone step at a time
Step backSn = T−1(Sn+1 − B)take B away first
No shortcutSn ≠ TnS0 + Bwork step by step

Learn · 11D

Adding or removing at every step: Sₙ₊₁ = TSₙ + B

Move with T, then add B

  • Sn+1 = TSn only works when the total never changes
  • B = a column matrix: + is added (restocking), − is removed (culling), in each state, every step
  • the total changes by the sum of B each step
  • no Tn shortcut: S1, then S2, then S3 …
  • going back: Sn = T−1(Sn+1 − B)
Next stateSn+1 = TSn + B
Step backSn = T−1(Sn+1 − B)
B =
−5cows
0goats
10sheep
5 cows culled, no goats added or removed, 10 sheep restocked: every month
S0→ × T → + B →S1→ × T → + B →S2→ …
Multiply by T first, then add B. Adding B before multiplying gives a different (wrong) answer.
