Today’s lesson

Today’s lesson

Learning intentions

  • To be able to identify activities in a project.
  • To be able to understand the precedence that some activities have over others in a project.
  • To be able to identify immediate predecessors of activities from an activity network.
  • To be able to draw an activity network from a precedence table.
  • To be able to understand and explain the need for dummy activities in projects.
  • To be able to include dummy activities in activity networks as required.

Success criteria

  • I can create an activity network from a precedence table.
  • I can write down a precedence table from an activity network.
  • I can decide when to use dummy activities in an activity network.

Key definitions

Precedence tableeach activity and its immediate predecessors
Activity networkdirected graph: edges = activities, vertices = where they start and finish
Start / finishthe only labelled vertices; one of each
Dummy activitydashed edge, takes no time; not a real activity
Patha walk with no repeated vertices or edges (Year 11)

Precedence tables and activity networks

Edges are activities

  • immediate predecessor: must be finished just before the next activity starts
  • precedence table: each activity and its immediate predecessors
  • in the activity network each activity is a directed edge; only start and finish are labelled
  • “–” activities leave the start; activities that are nobody’s predecessor go to the finish

Learn · 14C

Dummy activities

Some, but not all, the same

  • when two activities share some, but not all, of their immediate predecessors, one edge can’t show both
  • draw a dummy: a dashed edge, zero time, not a real activity
  • it runs from the end of the shared predecessor to the start of the activity with the extra predecessor
Dummy activitydashed, zero time
Directionend of shared → start of extra
ActivityImmediate predecessors
A–
B–
C–
DA, B
EB, C
D needs A and B; E needs B and C: two dummies from the end of B
A dummy is never written as a predecessor in the table.
