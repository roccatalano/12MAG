1ATypes of dataStudy Design: types of data
Categorical names a quality or group
Nominalnames only, no order
eye colour, car brand
Ordinalnames and a natural order
fitness level, shirt size
Numerical a quantity
Discretecounted: how many?
number of pets, pulse rate
Continuousmeasured: how much?
height, time, weight, age

Not sure? Two tests

1 · Can you average it? Average weight makes sense; average house number doesn't. Numbers that are only labels are categorical.
2 · How was it recorded? Weight in kg → numerical. Weight as 'under 60 kg', '60–80 kg', 'over 80 kg' → ordinal.
Age is continuous, even when recorded in whole years.

1BDisplaying and describing categorical dataStudy Design: display and description of categorical variables; using distributions to answer statistical questions

Frequency table

Lists each category and how often it occurs, as a number and a percentage.

Percentage frequency

percentage frequency =\[\small \dfrac{\text{number of times a value occurs}}{\text{total number of values}}\times100\%\]
  1. One row per category, columns for number and %.
  2. Count each category; add the total.
  3. Each % = count ÷ total × 100.
  4. Check the % column adds to 100 (99.9 or 100.1 is just rounding).

Bar chart

  1. Frequency (or %) on the vertical axis.
  2. One bar per category, gaps between bars, all the same width.
  3. Label both axes; use a ruler.
  4. Ordinal data: keep the categories in order.

Percentage segmented bar chart

One bar, 100% tall, split into one segment per category. Shows each category's share of the whole and makes groups easy to compare.

Example 4 · same data

  1. Cold: 0 to 13%
  2. Mild: 13 to 13 + 60.9 = 73.9%
  3. Hot: 73.9 to 100%
  4. Shade each segment; add a legend.

Describing the distribution

Mode (modal category) = the most common category: tallest bar or longest segment.
The variable of number individuals were classified as categories. The majority / most individuals, %, were found to modal category. Of the remaining individuals, % were category, while % were category.

Tip

Say 'the majority' only when the modal category is over 50%; otherwise say 'the most common'. Always give the context and the %.

Example 5 · report on climate types

The climate types of 23 countries were classified as being, ‘cold’, ‘mild’ or ‘hot’. The majority of the countries, 60.9%, were found to have a mild climate. Of the remaining countries, 26.1% were found to have a hot climate, while 13.0% were found to have a cold climate.
