Today’s lesson

Learning intentions

  • To be able to identify and work with binary matrices, permutation matrices and communication matrices.
  • To be able to construct and interpret dominance matrices.

Success criteria

  • I can use a permutation matrix to rearrange the elements of a column or row matrix.
  • I can construct a permutation matrix to rearrange the elements of a column or row matrix in a given order.
  • I can find the inverse of a permutation matrix.
  • I can construct a communication matrix from information given in written form or a diagram.
  • I can construct a dominance matrix from information given in written form or a diagram.

Binary and permutation matrices

A permutation matrix rearranges another matrix

  • binary matrix: only 0s and 1s
  • permutation matrix: square, binary, exactly one 1 in every row and every column
  • PX (P in front) rearranges the rows of X; XP rearranges the columns
  • a 1 in row i, column j of P: row j of X moves to row i

Communication matrices

Rows send, columns receive

  • communication matrix C: 1 = a one-step (direct) link from row to column
  • C2 counts the two-step links (through one other person)
  • non-zero elements on the leading diagonal = redundant links (back to yourself)
  • T = C + C2: all one- and two-step links

Dominance matrices

Who is the strongest? Add up the rows

  • dominance matrix D: 1 = the row player beat (dominates) the column player
  • row sums of D = one-step dominance scores
  • D2 = two-step dominances (beat someone who beat them)
  • ties? rank by the row sums of T = D + D2
One-steprow sums of D
TotalT = D + D2
Birgit beat Cas, Cas beat Di
→ Birgit has a two-step dominance over Di
In a round-robin tournament everyone plays everyone once.
