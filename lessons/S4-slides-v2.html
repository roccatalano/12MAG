Learning intentions

1G Boxplots

Learning intentions

  • To be able to construct the boxplot for displaying the distribution of a numerical data.
  • To be able to define and identify outliers.
  • To be able to construct both simple boxplots and boxplots with outliers.
  • To be able to determine the features of a distribution from a boxplot.
  • To be able to use a CAS calculator to construct a boxplot.

  • ☐ I can read values from a boxplot.
  • ☐ I can estimate percentages from a boxplot.
  • ☐ I can use boxplots to describe a distribution without outliers.
  • ☐ I can use boxplots to describe a distribution with outliers.
  • ☐ I can use boxplots to answer statistical questions.

1G

Key ideas

1G Boxplots

Key definitions

Five-number summary: minimum, $Q_1$, median, $Q_3$, maximum
Boxplot: a picture of the five-number summary; the box holds the middle 50%
Whiskers: run from the box to the smallest and largest values that are not outliers
Outlier: a value below the lower fence or above the upper fence, drawn as a dot

Key formulas

Median position$\dfrac{n + 1}{2}$th value
Interquartile range$\text{IQR} = Q_3 - Q_1$
Range$\text{range} = \text{max} - \text{min}$
Lower fence$\text{LF} = Q_1 - 1.5 \times \text{IQR}$  $x < \text{LF}$ → outlier
Upper fence$\text{UF} = Q_3 + 1.5 \times \text{IQR}$  $x > \text{UF}$ → outlier
Cambridge General Mathematics Units 3&4, 1F pp. 44–47 and 1G pp. 61–64. Fences: VCAA formula sheet.

Outliers: the 1.5 × IQR fences

1G Boxplots

An outlier is more than 1.5 IQRs below $Q_1$ or above $Q_3$. It is drawn as a dot; the whisker stops at the last value inside the fence. 19 marks: $Q_1 = 23$, $M = 30$, $Q_3 = 35$.

1 $\text{IQR} = 35 - 23 = 12$
2 $\text{LF} = 23 - 18 = 5$, $\text{UF} = 35 + 18 = 53$
3 $3 < 5$: 3 is an outlier (a dot). Nothing is above 53.
Whiskers: down to 21 (smallest non-outlier), up to 48 (the max).

Reading shape from a boxplot

1G Boxplots

Where does the median sit in the box? Which whisker is longer? The long side is the tail. Click for each shape.

Symmetric

Median near the middle; whiskers about equal.

Positively skewed

Median to the left of the box; long right whisker.

Negatively skewed

Median to the right; long left whisker.

With outliers

Dots separated from the whiskers.
Describe with SOCS, like a sock: Shape · Outliers · Centre (the median) · Spread (IQR and range).
