Key ideas

Key definitions and formulas

Key definitions

Weighted grapha graph with a number (weight) on each edge
Networka weighted graph whose weights are physical quantities: distance, time, cost
Shortest paththe route between two vertices with the smallest total weight
By inspectionlist the possible routes and add their weights
Dijkstra’s algorithma step-by-step method that finds the shortest path from a starting vertex

Key formulas

Length of a routeadd the weights of its edgese.g. 7 + 9 + 11 = 27 km
Dijkstra · updatenew label = circled label + edge weightkeep the smaller of the new and old label
Dijkstra · nextcircle the smallest uncircled labelstop when the destination is circled
Backtrackdestination label − edge weight = previous circled labelgives the route

Weighted graphs and networks

Numbers on the edges

  • weighted graph: each edge carries a number, its weight
  • weights can be distances, times or costs
  • when the weights are physical quantities, the weighted graph is a network
Weighted grapha weight on every edge
Networkweights are distance, time or cost
Vertices = towns, edges = roads, weights = distances (km)
Bartow to Croghon is 12 km
Bartow → Stratmoore → Osburn: 7 + 9 = 16 km
The drawing is not to scale: a long edge can have a small weight. Use the numbers, not the picture.

Shortest path by inspection

List, add, compare

  1. list the sensible routes from start to finish
  2. add the weights along each route
  3. the smallest total is the shortest path: give its length and its route
Shortest pathsmallest total weight
Ignore routes that are obviously long (they go the wrong way)
Watch for a short first step that pays off later
Shortest path = length AND route. Write both: “13 km, D–B–H–E”.

Dijkstra’s algorithm

Grow the shortest paths out from the start

  1. label the start 0 and circle it
  2. from the vertex just circled, label each neighbour: circled label + edge weight (keep the smaller if it already has one)
  3. circle the smallest uncircled label
  4. repeat 2–3 until the destination is circled: its label is the shortest length
  5. backtrack: label − edge weight = the circled vertex before it
Updatecircled label + edge weight
Nextsmallest uncircled label

B841620
Same steps in a table (Edrolo): one row per circled vertex; a box = circled
A to D = 16, route A–B–D
A circled label never changes. Once the destination is circled, stop: you do not need to label every vertex.

Using Dijkstra’s algorithm: graphical method

Find the shortest path from A to F in the weighted graph shown below.
  1. 1Step 1A = 0, circled
  2. 2Step 2from A: B = 2, C = 6 · circle B (2)
  3. 3Step 3from B: E = 2 + 2 = 4, D = 2 + 3 = 5, C = 2 + 2 = 4 < 6 · circle C (4)
  4. 4Step 4from C: D = 4 + 1 = 5 (no better) · circle E (4) · from E: F = 4 + 3 = 7 · circle D (5): F = 5 + 5 = 10 > 7 · circle F (7)
  5. 5Step 5backtrack: 7 − 3 = 4 (E), 4 − 2 = 2 (B), 2 − 2 = 0 (A)
  1. ✓AnswerThe shortest path from A to F is A–B–E–F with a length of 7.
