Question 83 marks

Let Vₙ represent the value of an item after n uses, in dollars. The value of the item depreciating using the unit cost method could be modelled using the following recurrence relation.

Edrolo U3&4 5B Q8

$184
bWhat will the value of the item be after four uses? (1 mark)
V₄ = 184 − 4 × 14 = $128
cAfter how many uses will the item be worth $100? (1 mark)
