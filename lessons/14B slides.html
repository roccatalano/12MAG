Bipartite graphs and allocation

Two groups, one match each

  • a bipartite graph has two groups of vertices (e.g. people and tasks)
  • each edge joins a vertex in one group to a vertex in the other
  • allocation: match each person to exactly one task
  • start with a vertex that has only one edge: that match is forced
Bipartite graphtwo groups; edges go across
Allocationone task each
Every employee can use every machine: a complete bipartite graph
Too many edges to weigh: put the costs in a table (cost matrix)
Highlight the forced matches first, then cross out what they rule out.

Bipartite graphs and allocation

Nick, Maria, David and Subitha are presenters on a TV travel show. Each presenter will be assigned a story to film about one country that they have visited before.
  • Nick has visited Greece, Malaysia and Brazil
  • Maria has visited Greece and France
  • Subitha has visited Malaysia and Brazil
  • David has visited Malaysia
Construct a bipartite graph of the information above and use it to decide on the assignment of each presenter to one country.
  1. 1Graphpresenters in one column, countries in the other; join each presenter to each country visited (picture)
  2. 2ForcedDavid has visited only Malaysia → David–Malaysia · only Maria has visited France → Maria–France
  3. 3EliminateMaria is used, so Greece → Nick · Subitha is left with Brazil
  1. ✓AnswerNick: Greece · Maria: France · David: Malaysia · Subitha: Brazil.

Allocation by inspection

Small problems: look for the best total

  • the cost matrix: rows = people, columns = tasks
  • find the cheapest person for each task
  • if two tasks want the same person, give that person the task where they save the most
  • minimum cost = sum of the chosen entries

The Hungarian algorithm

Make zeros, then allocate on them

  1. subtract each row’s smallest value from that row
  2. cover all zeros with the fewest lines: lines = rows? go to 6
  3. subtract each column’s smallest value (columns with no zero)
  4. cover the zeros again: lines = rows? go to 6
  5. smallest uncovered value k: subtract k from uncovered, add k to values covered twice; repeat 4
  6. draw a bipartite graph of the zeros; allocate; add the original costs
Lines = allocationsthen allocate
Adjust− k uncovered, + k twice
ABCD
Wendy0102030
Xenefon4001040
Yolanda3020300
Zelda0603050
Shaded = a covering line
3 lines but 4 allocations: not yet
Lines go along whole rows or columns, never diagonally.
