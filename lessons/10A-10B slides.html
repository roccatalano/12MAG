Today’s lesson

Today’s lesson

Learning intentions

  • To be able to state the order of a given matrix.
  • To be able to describe the location of an element in a matrix.
  • To be able to determine the transpose of a matrix.
  • To be able to define and recognise diagonal, symmetric and triangular matrices.
  • To be able to define and recognise identity matrices.
  • To be able to represent data given in a table by a matrix.
  • To be able to represent a network diagram with a matrix.

Success criteria

  • I can state the order of a given matrix.
  • I can find the transpose of a matrix.
  • I can identify a matrix as being a square, column or row matrix.
  • I can identify a square matrix as being an identity or diagonal or symmetric or upper/lower triangular matrix.
  • I can identify the aij term in a matrix A.
  • I can construct a matrix given a rule for aij.
  • I can enter a matrix into a CAS calculator.
  • I can enter information from a table into a matrix.
  • I can represent a network diagram by a matrix.
  • I can interpret a matrix representing a network diagram.

What is a matrix?

Rows × columns

  • a matrix is a rectangular array of numbers (elements)
  • order = rows × columns (rows first)
  • aij = element in row i, column j
  • row matrix: 1 row · column matrix: 1 column · square: rows = columns
  • transpose AT: rows become columns

Types of square matrices

Look at the leading diagonal

  • leading diagonal: top left → bottom right
  • diagonal: zeros everywhere off it
  • identity I: diagonal with all 1s
  • symmetric: mirror image across it (AT = A)
  • upper / lower triangular: zeros below / above it
