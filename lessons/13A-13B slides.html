Today’s lesson

Today’s lesson

Learning intentions

  • To be able to define and identify a graph, vertex, edge and loop.
  • To be able to find the degree of a vertex and the sum of degrees.
  • To be able to describe the features of a graph.
  • To be able to define and identify a planar graph and its faces.
  • To be able to apply Euler’s formula and use it to verify if a graph is planar.
  • To be able to use an adjacency matrix to represent a graph.

Success criteria

  • I can identify edges, vertices and loops in a graph.
  • I can determine the degree of a vertex in a graph.
  • I can identify simple graphs, isolated vertices, degenerate graphs, connected graphs, bridges and subgraphs.
  • I can recognise isomorphic graphs.
  • I can redraw graphs in planar form.
  • I can use Euler’s formula.
  • I can write an adjacency matrix from a graph.
  • I can construct a graph from an adjacency matrix.

Graphs: vertices, edges and degree

A graph shows connections

  • vertex = a dot (a person, town, room …)
  • edge = a line joining two vertices
  • degree deg(A) = number of edges at A
  • loop = an edge from a vertex to itself: adds 2 to the degree
Sum of degrees2 × number of edges
Anna is a friend of Brett, Ethan and Frances: deg(A) = 3 (odd)
Dario: deg(D) = 2 (even)
Ethan adds himself: a loop. deg(E) = 2 + 2 = 4
Count edge ENDS at the vertex: a loop has two ends there. Sum of degrees = 2 × number of edges.

Subgraphpart of a graph: every edge and vertex is in the original

Planar graphs and faces

Can it be drawn with no edges crossing?

  • edges that cross are NOT joined (no vertex at the crossing)
  • planar: it can be redrawn with no crossings (same connections)
  • faces: the regions a planar graph makes, including the outside
Isomorphicsame connections, different drawing
Move C–E round the outside: no crossings → the graph is planar.
Count faces only on a planar drawing; the outside region is always a face.

Euler’s formula

For any connected planar graph

v + f = e + 2

  • v vertices · e edges · f faces (include the outside)
  • verify: count v, e, f; show both sides are equal
  • use: substitute two values, solve for the third
Euler’s formulav + f = e + 2
6 vertices, 9 edges, 5 faces: 6 + 5 = 9 + 2 = 11 ✓
Euler’s formula only works on a planar drawing: redraw first, then count faces.

Adjacency matrices

A matrix that records the connections

  • one row and one column per vertex (square)
  • entry = number of edges joining the row vertex and the column vertex
  • a loop counts as 1 (on the leading diagonal)
  • an undirected graph gives a symmetric matrix
Adjacency matrixentry = number of edges joining i and j; loop = 1
ABCDE
A01101
B10210
C12000
D01000
E10000
row A, column B = 1: one edge joins A and B
row C, column B = 2: two edges join C and B
row A, column D = 0 (no edge) · row A, column A = 0 (no loop)
Row sums give the degrees, except that a loop adds 2 to the degree but only 1 to the matrix.
