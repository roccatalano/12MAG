Key ideas

Key definitions and formulas

Key definitions

log transformationreplace x by log x (or y by log y); log means log10
log xcompresses the high x-values; y-values unchanged
log ycompresses the high y-values; x-values unchanged
Undo a logif log y = k, then y = 10k

Key formulas

log x liney = a + b × log xthe “x” on the CAS is log x
log y linelog y = a + b × xthe “y” on the CAS is log y
Undo log yy = 10log ywork out log y first

  3. 3Same slopethe points (log x, y) lie on one line

Taking the log of one axis straightens a curve

The log transformation

  • it compresses the upper end of one axis
  • log x: squeezes the high x-values (y unchanged)
  • log y: squeezes the high y-values (x unchanged)
  • log means log10
log xcompresses the high x-values
log ycompresses the high y-values
log x straightens
→
log y straightens
→
Squared stretches the top of an axis; log squeezes it.

Fitting and using the line

Same four steps as 4A

  1. Make a new column: log x (or log y)
  2. Plot and check it is now linear
  3. Fit the least squares line to the transformed data
  4. Write it in the variable names, then substitute to predict
log x liney = a + b log x
log y linelog y = a + b x
lifespan = 54.3 + 5.59 × log(GDP)
log(cases) = 1.046 + 0.227 × day
log y on the left? Work out log y, then 10log y

Using the log x transformation:
• linearise the data, and fit a regression line to the transformed data (GDP is the EV)
• write its equation in terms of the variables lifespan and GDP rounded to three significant figures.
• use the equation of the regression line to predict the lifespan in a country with a GDP of $20 000, rounded to one decimal place.

TI-Nspire

  1. Lists & Spreadsheet: enter the data in named lists (e.g. lifespan, gdp).
  2. Name a new column for the transformed variable (e.g. lgdp) and in its formula cell type =log(gdp) (or =gdp^2, =1/gdp).
  3. Add Data & Statistics: plot the RV against the transformed variable (check the plot is now linear).
  4. Menu › Analyze › Regression › Show Linear (a+bx). The x in the equation is the transformed variable.
  5. Write the equation in the variable names, e.g. lifespan = 54.3 + 5.59 × log(GDP); substitute to predict (undo a log y or 1/y at the end).

ClassPad

  1. Statistics app: enter the data in named lists (e.g. Lifespan, GDP).
  2. Name a third list (e.g. logGDP) and in its calculation cell at the bottom type log(GDP) (or GDP^2, 1/GDP).
  3. SetGraph: Scatter, XList = transformed list, YList = RV; draw it and check the plot is linear.
  4. Calc › Regression › Linear Reg with the same lists: read a, b, r²; the x is the transformed variable.
  5. Write the equation in the variable names; substitute to predict (undo a log y or 1/y at the end).
