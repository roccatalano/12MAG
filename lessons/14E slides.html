Key definitions and formulas

Key definitions

Crashingreducing the duration of activities to reduce the completion time of a project
Critical paththe longest path; only crashing critical activities shortens the project
New critical pathanother path can become just as long: then it must be crashed too
Minimum costcrash the cheapest activities that shorten ALL critical paths

Key formulas

Path lengthpath length = sum of its durationslist every path start → finish
Completion timeminimum completion time = longest pathafter crashing: recheck every path
Crash costcost = Σ (days reduced × cost per day)stop crashing once it no longer helps

Crashing

Shorten the critical path

  • crashing = reducing activity times (more staff, better equipment) to finish sooner
  • only critical activities matter: others already have float
  • list every path and its length; the longest is critical
  • crash, then recheck every path: another path may become critical
Completion timelongest path
New critical pathrecheck every path
Critical path D–E: 13 hours
Crash D to 4 hours → 11 hours
Crashing A, B or C: no change
Crashing past the float of another path only moves the problem.

Crashing with cost

Most time saved for the least money

  • crash everything allowed by the maximum: find the new minimum time
  • then undo what isn’t needed: every path only has to get down to that time
  • prefer the cheaper activity; an activity on two long paths can be worth more
  • cost = days reduced × cost per day, added up
Crash costdays × cost
Minimum costcheapest that helps
F by 3 days: 16 → 13, but A–D–H is 14
so only 2 days are worth paying for: $200
Never pay to shorten a path below the new critical path.

Show what you know

The directed network below shows the sequence of activities, A to I, that is required to complete an office renovation.
The time taken to complete each activity, in weeks, is also shown.
The project manager would like to complete the office renovation in less time.
The project manager asks all the workers assigned to activity H to also work on activity F.
This will reduce the completion time of activity F to three weeks.
The workers assigned to activity H cannot work on both activity H and activity F at the same time.
No other activity times will be changed.
This change to the network will result in a change to the completion time of the office renovation.
Which one of the following is correct?
A.The completion time will be reduced by one week if activity F is completed before activity H is started.
B.The completion time will be reduced by three weeks if activity F is completed before activity H is started.
C.The completion time will be reduced by one week if activity H is completed before activity F is started.
D.The completion time will be reduced by three weeks if activity H is completed before activity F is started.
E.The completion time will be increased by three weeks if activity H is completed before activity F is started.
  1. 1Nowcritical A–C–E–F–G–I: 25 weeks
  2. 2F firstH must wait for F: A–C–E–F–dummy–H–I = 2 + 5 + 3 + 3 + 6 + 5 = 24
  3. 3H firstF waits for H: longer, not shorter
  1. ✓Answer · AThe completion time is reduced by one week if F is completed first: A.
  2. What’s the distractor?
    B B (36%) subtracts the full 3 weeks saved on F: H now has to follow F.
