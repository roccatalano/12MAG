Key ideas

Key definitions and formulas

Key definitions

Linear growth / decayadd / subtract the same amount D each step: the points lie on a straight line
Simple interestthe same amount of interest (a % of the principal) is added each year
Flat rate depreciationthe same amount (a % of the purchase price) is subtracted each year
Unit cost depreciationthe value drops by the cost per unit of use (per km, per use …)
Geometric growth / decaymultiply by the same R each step: the points lie on a curve
Compound interest · reducing balanceinterest added to / depreciation taken from the CURRENT value each year

Key formulas

LinearV0 = principal,   Vn+1 = Vn ± DD = r/100 × V0 (simple interest, flat rate) · D = cost per unit (unit cost)
GeometricV0 = principal,   Vn+1 = R × VnR = 1 + r/100 (compound interest) · R = 1 − r/100 (reducing balance)
Rate from the modelr = D ÷ V0 × 100%geometric: r = (R − 1) × 100%

Linear growth and decay

Add or subtract the same amount each step

  • Vn+1 = Vn + D: linear growth
  • Vn+1 = Vn − D: linear decay
  • D = the common difference; graph the terms as dots on a straight line (don’t join them)
LinearV0 = a,   Vn+1 = Vn ± D
P0 = 20,   Pn+1 = Pn + 2
20, 22, 24, …
Q0 = 20,   Qn+1 = Qn − 2
20, 18, 16, …
Upward line of dots = growth; downward = decay.

Simple interest

Simple interest = linear growth

  • the principal (amount borrowed or invested) is V0
  • the same interest D = r% of the principal is added every year
Simple interestV0 = principal,   Vn+1 = Vn + DD = r/100 × V0
$5000 at 4.8% p.a. simple interest
D = 4.8 ÷ 100 × 5000 = 240
V0 = 5000,   Vn+1 = Vn + 240
5000 → 5240 → 5480 → 5720 → …
Interest earned = current value − principal.

Flat rate depreciation

Flat rate depreciation = linear decay

  • an asset loses the same amount D every year
  • D = r% of the purchase price V0
  • scrap value: the value when the asset is no longer useful
Flat rateV0 = purchase price,   Vn+1 = Vn − DD = r/100 × V0
Car $24 000, 20% of the purchase price per year
D = 20 ÷ 100 × 24 000 = 4800
V0 = 24 000,   Vn+1 = Vn − 4800
24 000 → 19 200 → 14 400 → 9600 → 4800 → 0
Rate from the model: r = D ÷ V0 × 100%.

Unit cost depreciation

Value depends on USE, not time

  • D = cost per unit of use (per km, per page, per mow …)
  • Vn = value after n units of use
Unit costV0 = purchase price,   Vn+1 = Vn − DD = depreciation per unit of use
Mower $270, loses $3.50 each time it is used
V0 = 270,   Vn+1 = Vn − 3.50
270 → 266.50 → 263 → 259.50 → …
n counts uses, not years: read the question for the unit.

Geometric growth and decay

Multiply by the same R each step

  • Vn+1 = R × Vn
  • R > 1: geometric growth · R < 1: geometric decay
  • the points lie on a curve
GeometricV0 = a,   Vn+1 = R × Vn
V0 = 3,   Vn+1 = 2Vn
3, 6, 12, 24, …
V0 = 48,   Vn+1 = 0.5Vn
48, 24, 12, 6, …
Linear: same amount each step (+/−). Geometric: same percentage each step (×).

Compound interest

Interest is added to the CURRENT value

  • interest earned is added on, then earns interest itself
  • next value = current + r% of current = R × current
Compound interestV0 = principal,   Vn+1 = R × VnR = 1 + r/100
$5000 at 8% p.a., compounding yearly
next = current + 8% of current = 108% of current
R = 1 + 8/100 = 1.08
V0 = 5000,   Vn+1 = 1.08 × Vn
Growth: R = 1 + r/100 (8% → 1.08, not 0.08).

Reducing balance depreciation

Lose r% of the CURRENT value each year

  • the value decays geometrically
  • next value = current − r% of current = R × current
Reducing balanceV0 = purchase price,   Vn+1 = R × VnR = 1 − r/100
Sofa $7500, reducing balance 8.4% p.a.
R = 1 − 8.4/100 = 0.916
V0 = 7500,   Vn+1 = 0.916 × Vn
Decay: R = 1 − r/100 (8.4% → 0.916, not 0.084).
