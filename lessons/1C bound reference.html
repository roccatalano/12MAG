Frequency tables for numerical data

Discrete, few values: one row for every value from the minimum to the maximum (like categorical data).
Many values, or continuous: group into intervals, a grouped frequency table.
  1. Every value fits in exactly one interval: no overlaps, no gaps.
  2. About 5 to 15 intervals with easy widths (2, 5, 10, 100…).
  3. Start each interval on an exact value: 0–49, 50–99.
  4. Read 30–<40 as 'at least 30 but less than 40'.

Percentage frequency

\[\small \dfrac{\text{frequency}}{\text{total}}\times100\%\]

Writing a description

Cover all four, in context, with numbers:
  1. Shape: symmetric / positively or negatively skewed (name the tail).
  2. Centre: 'around …' with units.
  3. Spread: from min to max; where most values lie.
  4. Outliers: possible ones only, from a histogram.

Describing a distribution: shape, centre, spread, outliers

Symmetric
even tails either side
Positively skewed
long tail to the right
Negatively skewed
long tail to the left
Bimodal
two peaks: two groups?
Centre: the middle value, where the area splits in half.
Spread: narrow peak = tightly clustered; broad = widely spread.
Outliers: values that stand out from the main body. Check them.

Tip

The tail names the skew. From a histogram you can only estimate the centre and spread and flag possible outliers.

Example 9 · gestation period of 1000 babies

The distribution is clearly negatively skewed, with a long lower tail. The centre of the distribution is around 38-39 weeks. The data values range from 25-42 weeks, but most of the data values are close to the centre, in the range of 36-41 weeks. Those values which are less than 34 weeks seem to be small in comparison to the rest of the data, but which values are outliers cannot be determined from the histogram.
