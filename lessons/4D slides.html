Today’s lesson

Learning intentions

  • To be able to use the circle of transformations to determine which transformations may help linearise a non-linear association.
  • To be able to use a residual plot to assess the effectiveness of a data transformation.
  • To be able to use the coefficient of determination to assess the effectiveness of a data transformation.

Key ideas

Key definitions and formulas

Key definitions

circle of transformationsshows which transformations may straighten each of the four curve shapes
candidateseach shape has more than one possible transformation: try them all
residual plotthe best transformation leaves no clear pattern in the residuals
r²the best transformation has the highest coefficient of determination

Key formulas

Squaredx² or y²stretches the high values
Loglog10 x or log10 ycompresses the high values
Reciprocal1/x or 1/ycompresses the high values even more

Learn · 4D

The circle of transformations

Which transformation might straighten it?

  • match the curve to one of the four quarters of the circle
  • the labels beside that quarter are the possible transformations
  • there is more than one candidate each time
  • only for curves that keep going up or keep going down
Squaredx² or y²
Log or reciprocallog x, 1/x, log y, 1/y
Read the labels on the same side as the curve: top left uses y², log x or 1/x.

Learn · 4D

Which candidate is best?

Try each candidate, then compare

  1. Apply each possible transformation
  2. Look at each residual plot: no clear pattern = linear
  3. Compare r²: the higher, the better
  4. Close r²? Choose the one easier to interpret
Residual plotno pattern = linear
r²% of variation explained
residual plot with a curve → not linear yet
random scatter + highest r² → best transformation
Write the final equation in the variable names, e.g. age = 5.098 + 0.091 × diameter².

  1. 1Circleincreasing, curving up: x², 1/y or log y

  3. 31/yresiduals still curved · r² = 75.7%

TI-Nspire

  1. Make a column for each transformation to try (x², log x, 1/x or y², log y, 1/y) as in "Fitting a regression line to transformed data".
  2. For each one: Data & Statistics plot, Show Linear (a+bx), turn on Diagnostics to show r².
  3. Menu › Analyze › Residuals › Show Residual Plot: look for no clear pattern.
  4. Choose the transformation with the patternless residual plot and the highest r².

ClassPad

  1. Make a list for each transformation to try (e.g. x², log x, 1/x).
  2. For each one: Calc › Regression › Linear Reg (XList = transformed list) and read r².
  3. Set Copy Residual to a list, then plot residuals against the transformed list as a scatterplot: look for no clear pattern.
  4. Choose the transformation with the patternless residual plot and the highest r².
