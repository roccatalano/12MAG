Today’s lesson

Learning intentions

  • To be able to understand the mean and the median as measures of centre.
  • To be able to understand the range, interquartile range and standard deviation as measures of spread.
  • To be able to know whether to use the median and interquartile range, or the mean and standard deviation, for a particular distribution.
  • To be able to use a CAS calculator to calculate these summary statistics.

  • I can find the median value in a data set.
  • I can find the median value from a dot plot.

  • I can find the range from a stem plot.
  • I can find the IQR from a stem plot when n is even.
  • I can find the IQR from a stem plot when n is odd.
  • I can calculate the mean using the formula.
  • I can calculate the mean and standard deviation using the CAS calculator.

Key ideas

Key definitions and formulas

Key definitions

Median (M)the middle value of the ordered data
Mean (x̄)the sum of the values divided by n: the balance point
Rangelargest value minus smallest value
Quartiles (Q1, Q3)split the ordered data into four equal groups; Q1 = median of the lower half, Q3 = median of the upper half
IQRthe spread of the middle 50% of the data
Standard deviation (s)the spread of the data around the mean; on CAS it is sx

Key formulas

Median positionposition = n + 12
Median, n evenM = first middle + second middle2
Rangerange = largest − smallest
Interquartile rangeIQR = Q3 − Q1
Meanx̄ = Σxn
Standard deviations = √Σ(x − x̄)²n − 1use CAS: sx, not σx

    Two questions about any distribution

    Where is the centre? How spread out is it?

    Centre: median M (the middle value) · mean x̄ (the balance point)
    Spread: range · IQR (the middle 50%) · standard deviation s (spread around the mean)

    Median positionposition = n + 12
    Meanx̄ = Σxn
    median goes with IQR
    resistant: outliers barely move them
    mean goes with standard deviation
    use when symmetric, no outliers
    They come in pairs: median with IQR · mean with standard deviation. In a SOCS answer, C and S use the same pair.

    The median: the middle value

    The median is the middle value in an ordered data set. For n data values it is at the n + 12th position.

    Odd number of values

    19326123412415302127
    1. 1Write the data in order. Count them: n = 11
    2. 2Position: (11 + 1) ÷ 2 = 6th value
    3. 3Cross off the smallest and the largest, again and again: one value is left. M = 21

    Even number of values

    93125102146114
    1. 4Write the data in order. Count them: n = 10
    2. 5Position: (10 + 1) ÷ 2 = 5.5th: halfway between the 5th and 6th values
    3. 6Cross off pairs: two values are left, 6 and 9. The median sits on the line between them: M = (6 + 9) ÷ 2 = 7.5

          Mean or median?

          Choosing between the mean and the median

          The mean and the median are both measures of the centre of a distribution. If the distribution is:

          • symmetric and there are no outliers, either the mean or the median can be used to indicate the centre of the distribution
          • clearly skewed and/or there are outliers, it is more appropriate to use the median to indicate the centre of the distribution.

          Symmetric, no outliers

          mean ≈ median: either can be used

          Clearly skewed and/or outliers

          the tail drags the mean: use the median

          SOCS: the C line names the measure you chose (‘centred at …, the median’), and the S line uses its partner (IQR with the median).
