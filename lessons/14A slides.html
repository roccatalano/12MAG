Today’s lesson

Today’s lesson

Learning intentions

  • To be able to define and describe flow.
  • To be able to calculate the maximum flow through a flow network by observation.
  • To be able to identify cuts and calculate cut capacities.
  • To be able to determine the maximum flow through a flow network by finding the capacity of the minimum cut.
  • To be able to solve flow problems by finding minimum cut capacities.

Success criteria

  • I can define and describe a directed graph.
  • I can determine the maximum flow for any section of sequential edges of a directed graph.
  • I can determine cut capacities.
  • I can determine the maximum flow as equal to the minimum cut capacity.

Key definitions and formulas

Key definitions

Directed grapha graph whose edges have arrows: travel one way only
Source / sinkwhere the flow starts / where it ends
Capacitythe weight on an edge: the most that can flow along it
Cuta line that completely separates the source from the sink
Cut capacitysum of the cut edges flowing source side → sink side
Minimum cutthe cut with the smallest capacity

Key formulas

Edges in a rowflow = smallest capacitye.g. 300 then 600 then 800 → 300
Cut capacityadd only edges going source → sinkedges flowing back count 0
Max-flow min-cutmaximum flow = minimum cut capacitycheck every cut

Directed graphs and flow

Flow goes one way

  • a directed graph (digraph) has arrows: you can only travel the way they point
  • material flows from the source to the sink
  • the weight on each edge is its capacity
  • pipes in a row: the flow is the smallest capacity (the bottleneck)
Capacitymost that can flow
Edges in a rowflow = smallest capacity
A → B → C → E: 300, 600, 800
Bottleneck 300: only 300 cars per hour get through
Separate routes add up
Follow the arrows: an edge pointing the wrong way cannot be used.

Cuts and the maximum-flow minimum-cut theorem

Block every route

  • a cut separates the source from the sink completely
  • cut capacity = sum of the cut edges that flow from the source side to the sink side
  • an edge flowing back (sink side → source side) counts 0
  • maximum flow = capacity of the minimum cut
Cut capacitysource → sink edges only
Max-flow min-cutmax flow = min cut
C1: 15 + 20
C2: F → B flows back: not counted
Smallest cut = the bottleneck of the whole network
Check each arrow a cut crosses: does it point towards the sink?

Tracking flow and more than one source

Push the flow through

  • edges leaving the source run full
  • at each vertex: flow out ≤ flow in; cross out a capacity that can’t be reached and write the real flow
  • maximum flow = total arriving at the sink
  • two sources / outlets: look at each outlet on its own (cut off that outlet)
Max-flow min-cutmax flow = min cut
B gets 15: 10 to C, only 5 left for D
A group must fit every edge on its route
Use a minimum cut to check a tracked answer: they must agree.
