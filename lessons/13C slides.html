Walks, trails and paths

Ways of travelling through a graph

  • walk: any sequence of edges (repeats allowed)
  • trail: a walk with no repeated edges
  • path: no repeated edges and no repeated vertices
  • write a walk as its vertices in order: A–C–A–D–G
Trailno repeated edges
Pathno repeated vertices
Walk · A–C–A–D–G
edge A–C used twice
Trail · B–E–F–C–B–A
no repeated edge; B repeated
Path · A–D–C–F–E–B
nothing repeated
Trail = no repeated EDGES. Path = no repeated edges or VERTICES. Every path is a trail; every trail is a walk.

Circuits and cycles

Walks that end where they start

  • circuit: a trail that starts and ends at the same vertex
  • cycle: a path that starts and ends at the same vertex
  • the start/end vertex does not count as a repeat
Circuitclosed trail
Cycleclosed path
Circuit · A–C–F–G–D–C–B–A
no repeated edge; C repeated
Cycle · F–E–B–C–F
nothing repeated
openclosed (same start/end)
edges repeatwalkwalk
no repeated edgestrailcircuit
no repeated verticespathcycle
Ask two questions: same start and end? Then what repeats: an edge, a vertex, or nothing?

Eulerian trails and circuits

Every Edge exactly once

  • Eulerian circuit: connected and every vertex has even degree; start anywhere
  • Eulerian trail: connected and exactly two odd vertices; start at one odd vertex, finish at the other
  • more than two odd vertices: neither
Eulerian circuitall even
Eulerian trailexactly two odd
Count degrees: A 3 · B 2 · C 4 · D 2 · E 1
Exactly two odd vertices (A and E) → an Eulerian trail from A to E
A–C–A–B–C–D–E uses every edge once
Cambridge counts a circuit as a special trail (zero odd vertices). Edrolo and most exam questions say “Eulerian trail” only when there are exactly two odd vertices: answer the question that is asked.

Hamiltonian paths and cycles

Every vertex exactly once

  • Hamiltonian path: visits every vertex once (it need not use every edge)
  • Hamiltonian cycle: a Hamiltonian path that returns to its start
  • no rule: find one by inspection (trial)
Hamiltonianevery vertex once
Start at A and visit B, E, F, G, D, C once each
A–B–E–F–G–D–C is a Hamiltonian path
Add C–A: A–B–E–F–G–D–C–A is a Hamiltonian cycle
Eulerian = Edges (both start with E). Hamiltonian = vertices: don’t repeat a vertex, and you may skip edges.
