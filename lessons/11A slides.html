Key ideas

Key definitions and formulas

Key definitions

Stateone of the categories something can be in (e.g. a town, a machine that is operating or broken)
Transition diagramone point per state; arrows (and loops) show the % that move each period; the % leaving each point add to 100%
Transition matrix Tthe proportions moving between states: columns = from (this period), rows = to (next period)
State matrix Sna column matrix of the numbers in each state after n periods

Key formulas

Element tijtij = proportion moving from column state j to row state icolumn first: from → to
Column sumseach column of T adds to 1everyone ends up somewhere
% → proportion70% = 0.7divide by 100

    Learn · 11A

    From a transition diagram to a transition matrix

    Columns are FROM, rows are TO

    • one row and one column for each state, in the same order
    • fill one column at a time: every arrow (and loop) LEAVING that state
    • write each % as a proportion (20% = 0.2)
    • each column adds to 1
    Element tijfrom column j → to row i
    Column sumseach column adds to 1
    T =
    BC
    0.80.1B
    0.20.9C
    column = rented in · row = returned to
    Column B: 80% stay (loop) + 20% to C = 100% ✓  ·  Column C: 10% + 90% = 100% ✓
    A loop is the % that STAY: it goes on the leading diagonal.

        Learn · 11A

        From written information to a transition matrix

        Label first, then fill each column

        • find the states and the time step (day, week, term …)
        • label columns ‘start / today / this week’ and rows ‘end / tomorrow / next week’
        • each sentence gives one element: ‘of those in X, …% move to Y’ → column X, row Y
        • a missing value = 1 − the rest of its column
        Columnsfrom · today · start · this week
        Rowsto · tomorrow · end · next week
        “20% of workers at station A today move to station B tomorrow”
        T =
        AB
        ··A
        0.2·B
        column A (today), row B (tomorrow)
        so 1 − 0.2 = 0.8 of station A stay at A (row A, column A)
        Words like ‘today’, ‘from’, ‘start’ name the COLUMNS.
