Key ideas

Key definitions and formulas

Key definitions

Centringsmoothing over an EVEN number of points puts each mean between two times; centring averages two neighbouring means so the value lines up with a real time
Two-mean with centringmean of (mean of the value and the one before) and (mean of the value and the one after)
Four-mean with centringmean of two four-means: one ending at the value + 1, one starting at the value − 1
Lost pointsan n-mean with centring (n even) has no value for the first and last n ÷ 2 points

Key formulas

Two-mean centredsmoothed y2 = y1 + 2y2 + y34
Four-mean centredsmoothed y3 = y1 + 2y2 + 2y3 + 2y4 + y58
Centred meanmean 1 + mean 22

Learn · 5B

Why centre? Two-mean smoothing with centring

Even number of points → centring

  • the mean of an even number of values sits between two times
  • take the two means either side of the time …
  • … and average them: the centred mean lines up with that time
  • only needed for even smoothing: 2, 4, 6 …
Two-mean centredsmoothed y2 = y1 + 2y2 + y34
DayTemperatureTwo-moving meansWith centring
Monday18.1
 (18.1 + 24.8) ÷ 2 = 21.45
Tuesday24.8 (21.45 + 25.60) ÷ 2 = 23.525
 (24.8 + 26.4) ÷ 2 = 25.60
Wednesday26.4
Two-mean centred on Tuesday = (Mon + 2 × Tue + Wed) ÷ 4.

Learn · 5B

Four- and six-mean smoothing with centring

Same idea, bigger groups

  • four-mean centred: write down the five values centred on the time
  • mean 1 = first four, mean 2 = last four, then average
  • six-mean centred: seven values, two six-means
  • an n-mean with centring loses n ÷ 2 points at each end
Four-mean centredsmoothed y3 = y1 + 2y2 + 2y3 + 2y4 + y58
Lost pointsn ÷ 2 at each end
Four-mean centred = (y₁ + 2y₂ + 2y₃ + 2y₄ + y₅) ÷ 8: ends count once, middle three twice.
Cambridge General Mathematics Units 3&4, 5B pp. 271–273 (plot: Example 11)
