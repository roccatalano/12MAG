Key ideas

Key definitions and formulas

Key definitions

Sequencea list of numbers in order, separated by commas: 1, 3, 5, 7, …
Termeach number in a sequence
Recursiongenerating each term by applying the same rule to the term before
Recurrence relationa starting value + a rule that gives the next term from the current term
Iterationone application of the rule

Key formulas

Recurrence relationV0 = starting value,   Vn+1 = rule using Vn
Naming termsVn = term after n applications of the ruleV₀ is the starting value (no applications yet)
Next termVn+1 = the term after Vn

Learn · 7A

Sequences and rules

A starting value + a rule

  • a sequence is a list of numbers (terms) in order
  • ‘…’ means the sequence keeps going
  • recursion: apply the same rule to each term to get the next one
Sequence1, 3, 5, 7, 9, …
Start with 1, rule ‘add 2 to each term’:
1→ +2 →3→ +2 →5→ +2 →7→ +2 →9
A calculator remembers the last answer (ans), so it can repeat the rule for you: type the start, then the rule, then keep pressing enter.
Write the starting value as the first term: it counts as one of the ‘first five terms’.

Recurrence relations

Two parts: a starting value and a rule

  • Vn = the term after n applications of the rule
  • V0 = starting value (no applications yet)
  • Vn+1 = next term, worked out from the current term Vn
Recurrence relationV0 = 10,   Vn+1 = Vn + 5
In wordsIn symbols
Starting value = 10V0 = 10
Next term = current term + 5Vn+1 = Vn + 5
V0 = 10,   Vn+1 = Vn + 5 generates
1015202530
V0V1V2V3V4
The first term is V0, so the fifth term is V4: count from zero.

CAS · 7A

Generating a sequence from a recurrence relation

A sequence is generated by the recurrence relation

V0 = 300,   Vn+1 = 0.5Vn − 9

Generate the sequence on CAS and name each term: the first press after the rule gives V1.

The starting value is V₀, so the first press of enter/EXE after typing the rule gives V₁.

TI-Nspire

  1. Calculator page: type the starting value (e.g. 300) and press enter.
  2. Type the rule using the previous answer, e.g. ×0.5 − 9 (the calculator shows ans·0.5−9), and press enter.
  3. Keep pressing enter: each press gives the next term (V₁, V₂, V₃ …). Count the presses to name the term.

ClassPad

  1. Main application: type the starting value (e.g. 300) and press EXE.
  2. Type the rule using ans, e.g. ans × 0.5 − 9, and press EXE.
  3. Keep pressing EXE: each press gives the next term (V₁, V₂, V₃ …). Count the presses to name the term.
  1. ✓Read off300, 141, 61.5, 21.75, 1.875, −8.625 → V5 = −8.625 is the first negative term
