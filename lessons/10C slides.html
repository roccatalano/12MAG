Today’s lesson

Today’s lesson

Learning intentions

  • To be able to establish when two matrices are equal.
  • To be able to recognise when matrix addition and subtraction are defined and to perform these operations.
  • To be able to undertake scalar multiplication.
  • To be able to identify zero matrices.
  • To be able to undertake addition, subtraction and multiplication by a scalar with a CAS calculator.
  • To be able to use the operations of addition, subtraction and scalar multiplication of matrices in practical situations.

Success criteria

  • I can recognise when two matrices are equal and use this to solve problems.
  • I can add two matrices of the same order together.
  • I can subtract one matrix from another when they have the same order.
  • I can multiply a matrix by a scalar.
  • I recognise the role of the zero matrix and can undertake operations using the zero matrix.
  • I can use addition, subtraction and scalar multiplication to process data.
