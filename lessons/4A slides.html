Key definitions and formulas

Key definitions

Data transformationapplying a function to one axis (x or y, never both) to straighten (linearise) a curved scatterplot
x² transformationspreads out the high x-values; y-values unchanged
y² transformationspreads out the high y-values; x-values unchanged
Predictionsubstitute into the transformed line; if y was squared, take the positive square root at the end

Squaring one axis straightens a curve

The squared transformation

  • it stretches the upper end of one axis
  • x²: spreads out the high x-values (y unchanged)
  • y²: spreads out the high y-values (x unchanged)
  • use the one that turns the curve into a straight line
x² transformationspreads out the high x-values
y² transformationspreads out the high y-values
x² straightens

Transform one axis only: x² or y², never both.

Fitting and using the line

Four steps

  1. Make a new column: x² (or y²)
  2. Plot and check it is now linear
  3. Fit the least squares line to the transformed data
  4. Write it in the variable names, then substitute to predict
x² liney = a + b x²
y² liney² = a + b x
height = 1560 − 4.90 × time²
yield² = 4.45 + 2.29 × fertiliser
y² on the left? Work out y², then √ (keep the positive value)
The x (or y) on the CAS screen is the transformed variable: write x² (or y²) in your equation.

Transform, then fit the least squares line

The table shows the height (in m) of a base jumper for the first 10 seconds of her jump.

Time012345678910
Height15601555154015161482143813831320124611631070

a Construct a scatterplot displaying height (the RV) against time (the EV).
b Apply an x-squared transformation and fit a least squares line to the transformed data.
c Use the regression line to predict the height of the base jumper after 3.4 seconds.

TI-Nspire

  1. Lists & Spreadsheet: enter the data in named lists (e.g. lifespan, gdp).
  2. Name a new column for the transformed variable (e.g. lgdp) and in its formula cell type =log(gdp) (or =gdp^2, =1/gdp).
  3. Add Data & Statistics: plot the RV against the transformed variable (check the plot is now linear).
  4. Menu › Analyze › Regression › Show Linear (a+bx). The x in the equation is the transformed variable.
  5. Write the equation in the variable names, e.g. lifespan = 54.3 + 5.59 × log(GDP); substitute to predict (undo a log y or 1/y at the end).

ClassPad

  1. Statistics app: enter the data in named lists (e.g. Lifespan, GDP).
  2. Name a third list (e.g. logGDP) and in its calculation cell at the bottom type log(GDP) (or GDP^2, 1/GDP).
  3. SetGraph: Scatter, XList = transformed list, YList = RV; draw it and check the plot is linear.
  4. Calc › Regression › Linear Reg with the same lists: read a, b, r²; the x is the transformed variable.
  5. Write the equation in the variable names; substitute to predict (undo a log y or 1/y at the end).
