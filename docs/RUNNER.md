# Overnight runner instructions (AoS 2, 3, 4)

Each scheduled task "12MAG AoS N runner" (N = 2, 3 or 4) does ONE task from the "AoS N" section of docs/QUEUE.md per run, then starts the next run. The three runners work at the same time: never take or change tasks in another AoS section. Rocco is asleep: never wait for him for more than 10 minutes.

1. Read CLAUDE.md, PLANNER.md, docs/HANDOVER.md and docs/QUEUE.md in full (including "Notes for all AoS 2–4 runners"). CLAUDE.md's rules are binding (never write questions: copy verbatim and cite; planner card is the basis; slide/worksheet template rules; burnt-items ledger; % only from examiner reports; check every slide visually). Note your start time (Sydney).
   Load with ONE ToolSearch call: "select:mcp__claude-code-remote__list_triggers,mcp__claude-code-remote__fire_trigger,mcp__claude-code-remote__update_trigger,PushNotification".
2. Open questions first: for every question under "Questions for Rocco" prefixed 'AoSN' with no answer under "Answers from Rocco" and no Decisions log row, asked more than 10 minutes ago: decide with best judgement (CLAUDE.md rules first), apply it, add a Decisions log row, mark it "→ decided, see log". Apply Rocco's answers the same way (log as "Rocco: …").
3. Pick the task: in the "AoS N" section take the FIRST `todo` task (first chapter before second). If an AoS N task is `in progress` and started under 3 hours ago, another run owns it: stop. Over 3 hours: set it back to `todo` with a note and take it.
   No `todo` left: turn this scheduled task off (list_triggers → "12MAG AoS N runner" → update_trigger enabled=false), PushNotification "AoS N finished", add a line to HANDOVER.md, commit + push, stop.
4. Claim it: mark `in progress <Sydney date time>`, commit and push immediately (git -c push.negotiate=true push origin HEAD; if rejected: fetch --depth=50, rebase, retry — other runners push often).
5. Do the task. Sources are in the attached G: folder (mcp__remote-devices__ tools: stage to read, device_commit_files to write). Models: tools/deck/l16/build.py and tools/deck/l22/build.py (slides), their worksheet.py (worksheets), tools/cfat/ch5/ (CFATs), tools/revision/ch5/ (revision booklets), tools/test/ch5/build.py (chapter tests). New diagram types (e.g. networks, matrices): build a reusable helper once and reuse it. Re-read tools/ledger.csv and tools/ledger_manual.csv from origin before reserving exam items. Screenshot every slide (final + mid-reveal) and fix overflow. Everything is Draft; never mark Ready. Update the ledger and the planner card. Copy finished files flat into 01 Lesson materials on G: with CLAUDE.md naming.
   Questions for Rocco: add as the next Q-number prefixed 'AoSN' with Sydney time, commit + push, ONE PushNotification. Keep working on what doesn't depend on it. Before finishing, once 10 minutes have passed, re-read QUEUE.md from origin: apply any answer, otherwise decide and log (step 2). If the task truly can't be done, mark `needs Rocco — <why>`.
6. Finish: mark `done <date> — <one line>`, add a dated entry at the top of HANDOVER.md, add a Run log row (task 'AoSN #', start, finish, minutes, tokens if visible, result / what slowed it, "next run: fired" or "NOT fired — why"), commit and push.
7. REQUIRED: if AoS N still has a `todo` task, list_triggers → "12MAG AoS N runner" → fire_trigger with its id. If that fails, note it in the Run log row and push; the hourly schedule picks it up. Then stop.
